## Features

- **Canvas Drawing with SVG**  
  The canvas (not to be confused with HTML Canvas) is built using SVG (we're talking crisp rendering of shapes and texts)

- **Elements supported**  
  - **Rectangles, Circles, and Rhombuses**
  - **Lines and Arrows**
  - **Pencil (Freehand)**
  - **Text**

- **Element Selection and Editing**  
  - Click on an element to select it.
  - Resize handles at the corners.

- **Reposition elements by dragging**  

- **Zoom and Pan Functionality**  

- **Layer (Z-Index) Management**

- **Keyboard Shortcuts**  
  `Delete` (Windows) or `CMD + delete` (MacOS) to delete an element

- **Properties Sidebar**  

## Getting Started

1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Start the development server with `npm run dev`.
